# 🩺 SwasthyaGuide – Healthcare Android App

## 📌 Project Overview

**SwasthyaGuide** is an Android application designed to provide users with accessible healthcare guidance. The app is structured with a user-friendly interface and provides health-related information in a compact and intuitive format.

---

## 🧪 Project Details

- **Duration:** 1 Month  
- **Team Size:** 4  
- **Tools & Technologies:** Java, Android Studio, Gradle, GitHub Actions  

### ✅ Key Contributions

- Developed a functional and user-friendly **healthcare Android app** offering medical guidance and services.
- Implemented modular activities and clean navigation flows for seamless user experience.
- Used **Gradle** for build automation and dependency management.
- Integrated **CI/CD pipeline using GitHub Actions** to streamline development and deployment.
- Maintained clean code practices and used version control through Git.

---

## 📂 Project Structure Highlights

- `build.gradle` – Build configuration for dependencies and plugins
- `.idea/` – Android Studio project setup files
- `.github/workflows/android.yml` – CI/CD pipeline configuration

---

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Open the project in **Android Studio**.
3. Sync Gradle and build the project.
4. Run the app on an emulator or physical device.
