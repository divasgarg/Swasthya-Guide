# SwasthyaGuide

A project overview of a healthcare guidance app for Android. A four-person team built the project over one month using Java and Android Studio.

## Project highlights

- Organized account access and app navigation into Android activities and fragments.
- Used Gradle to manage dependencies and builds.
- Integrated GitHub Actions into the development workflow.

This repository contains the public project summary.
